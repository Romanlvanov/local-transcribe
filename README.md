# Локальная расшифровка видео и аудио

Всё считается на этом Mac, в облако ничего не уходит. Основа: `transcribe-local.py` из https://github.com/J3MeTron/Assistant, переделанный под Apple Silicon.

**Требования:** Mac на Apple Silicon (M1 и новее), macOS со стандартным `python3`, около 3 ГБ на диске (окружение и модели). Установка одной командой: `./setup.sh`.

- **Движок MLX** (по умолчанию) — Whisper `large-v3-turbo` на видеокарте M4. Быстро и точно.
- **Движок cpu** — faster-whisper на процессоре (`--engine cpu`). Запасной вариант.
- **Спикеры** — голосовой отпечаток каждой фразы (3D-Speaker через sherpa-onnx) и кластеризация. Даёт разметку «Спикер 1 / Спикер 2», работает без токенов и регистраций. Совсем мелкие «спикеры» (меньше 2% речи и меньше 20 с) приклеиваются к ближайшему.
- **Форматы** — `.txt` (таймкоды), `.md` (чистый текст абзацами или репликами, удобно отдавать в Claude), `.srt`, `.vtt`, `.json`.
- **Словарь терминов** — `terms.txt` подсказывает модели, как писать 1С, БСП, ЗУП и т.п.
- Пакетная обработка файлов и папок, веб-интерфейс в браузере.

Принимается всё, что понимает ffmpeg: mp4, mov, mkv, webm, avi, mp3, m4a, wav, ogg/opus, flac и др.

## Веб-интерфейс

```bash
./transcribe-ui.sh
```

Откроется http://127.0.0.1:8765 (доступ только с этого Mac). Что можно делать:
- перетащить файлы в окно или указать путь к файлу или папке;
- выбрать движок, модель, язык, разделение по спикерам и форматы;
- следить за очередью с прогрессом;
- отменить задание;
- смотреть текст с поиском, скачивать форматы, копировать текст, открывать файл в Finder;
- править словарь терминов.

Остановить сервер: Ctrl+C в терминале.

Куда сохраняется результат:
- **перетащенные файлы:** копия попадает в `uploads/`, результат в `output/`;
- **файлы по пути:** результат рядом с исходником (это можно переключить).

## Иконка в строке меню

```bash
./transcribe-menubar.sh
```

Справа вверху появится значок волны. Заполненный значок — веб-интерфейс работает, контур — остановлен. Во время расшифровки рядом виден процент.

В меню значка:
- статус сервера и текущее задание (процент, этап, сколько осталось);
- открыть интерфейс (если сервер остановлен, он сначала запустится);
- запустить или остановить сервер;
- папка с результатами;
- выход (вместе с сервером).

Сервер, запущенный отдельно через `transcribe-ui.sh`, значок тоже видит и может остановить. Журналы пишутся в `output/server.log` и `output/menubar.log`.

## Командная строка

```bash
./transcribe.sh "/путь/к/видео.mp4"
```

```bash
./transcribe.sh ~/Movies/Созвоны --diarize
```

| Опция | Что делает |
|---|---|
| несколько файлов / папок | папки обходятся рекурсивно; уже расшифрованные файлы (есть `.json`) пропускаются |
| `--force` | перерасшифровать, даже если результат есть |
| `--engine mlx\|cpu` | движок (по умолчанию `mlx`) |
| `--model large-v3-turbo\|large-v3\|medium\|small` | модель; для MLX можно указать и репозиторий `mlx-community/...` |
| `--language ru\|en\|auto` | язык, по умолчанию `ru` |
| `--diarize [--num-speakers N]` | разделить по спикерам; число спикеров можно не указывать, но если оно известно, точность выше |
| `--threshold 0.55` | порог сходства голосов (0.4–0.7): больше → больше спикеров. Если двух людей склеило в одного, поднимите; если одного разбило на двоих, опустите |
| `--formats txt,md,srt,vtt,json` | какие файлы писать (`json` пишется всегда) |
| `--terms файл.txt` / `--no-terms` | доп. словарь / без словаря |
| `--out папка` | куда класть результат (по умолчанию рядом с исходником) |
| `--probe` | только длительность |

Если в одной папке лежат файлы с одинаковым именем и разным расширением (`a.mp3` и `a.mp4`), результаты называются `a.mp3.txt` и `a.mp4.txt`, чтобы один не перезаписал другой. Записи длиннее 30 минут MLX обрабатывает кусками по ~20 минут, разрезая их по паузам. На 16 ГБ памяти это позволяет обрабатывать многочасовые файлы. Ориентир по скорости на M4: 35 минут речи распознаются примерно за 4,5 минуты.

Прогресс выводится в stderr. В stdout на каждый файл печатается одна JSON-строка с путями и статистикой. С флагом `--progress-json` прогресс тоже идёт JSON-строками, этим пользуется веб-интерфейс.

## Словарь терминов

`terms.txt`: по одному термину на строку, `#` — комментарий. Используются первые ~100 слов, поэтому важные термины ставьте наверх. Словарь подмешивается в каждое 30-секундное окно, а не только в первое, как было бы при штатном `initial_prompt`.

## Настройки по умолчанию

В `transcribe.config.json` задаются:
- движок;
- язык;
- модели для каждого движка;
- форматы;
- порог спикеров;
- `paths.hfHome` — папка для моделей, по умолчанию `models/`.

## Установка с нуля / переустановка

```bash
./setup.sh
```

Скрипт ставит `uv` и Python 3.12, создаёт `.venv`, ставит пакеты из `requirements.txt` и скачивает модели: turbo для MLX около 1,6 ГБ, модели спикеров около 40 МБ. sudo и brew не нужны.

## Устройство

- `transcriber/audio.py` — ffmpeg (из пакета static-ffmpeg) → WAV 16 кГц.
- `transcriber/engines.py` — движки MLX и faster-whisper:
  - VAD-фильтр галлюцинаций на тишине;
  - нарезка длинных сегментов по словам;
  - подмешивание словаря.
- `transcriber/diarize.py` — спикеры.
- `transcriber/writers.py` — форматы.
- `transcriber/pipeline.py` — конвейер и пакетная обработка.
- `transcribe-local.py` — CLI.
- `web/` — веб-интерфейс (FastAPI). Каждый файл обрабатывается отдельным процессом CLI.
- `menubar.py` — значок в строке меню (rumps).
